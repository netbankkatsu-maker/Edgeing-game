# 寸止めゲーム（メトロノーム連動エッジングゲーム）

画面の指示とメトロノームの拍に従って、イクのを我慢する18歳以上向けのゲームです。
参考スクリーンショット（100adults.com の寸止めゲーム）の見た目と構成をもとに、独自実装しました。

## 構成

- `index.html` — 本体（年齢確認 → 設定 → ゲーム → 結果）
- `styles.css` — ダーク＋ピンクのテーマ
- `app.js` — 設定・指示プール・メトロノーム（Web Audio）・抽選・同期／遠隔リンク
- `male.html` / `female.html` — 男性向け／女性向けの専用入口（`index.html?mode=male|female` へ遷移）
- `vercel.json` — Vercel 用設定（cleanUrls、`/male` `/female` のリライト）

ビルド不要の静的サイトです。環境変数も不要です。

## 機能

- 年齢確認ゲート（1枚目の見た目を再現）
- 設定（2〜6枚目の内容を再現）
  - プリセット（はじめて／標準／じっくり長め）
  - だれ向け（男性向け／女性向けで指示プールと文言が切り替わる）
  - 時間（3〜30分／カスタム／ランダム）、難易度（確率と配分が連動）
  - 最後（抽選／必ずイッていい／必ずお預け／手放し／連続／延長戦）
  - 「イッていい」の時間、寸止め後の待ち時間、指示の長さ
  - 指示タブ：指示の ON／OFF
  - 動画・画像タブ：自分の画像・GIF・動画をスライドショー表示（端末外に送信されません）
  - 音・声タブ：メトロノーム音（クリック／ビープ／ウッド、音量）、読み上げ、振動
  - その他タブ：2人同期リンク、小窓（Document Picture-in-Picture）、遠隔リンク
- ゲーム本体
  - 色で変わる指示（緑=しごく／黄=ゆっくり／赤=触らない／ピンク=乳首だけ／青=先だけ）
  - 指示ごとに BPM が変わるメトロノームと光のパルス
  - 「寸止めした」ボタンで許可率 +5%（最大 +20%）
  - 終了時に抽選 → 許可なら白いバーのカウントダウン、お預けなら結果画面（延長戦可）
- 2人で同時に遊ぶ：シード＋開始時刻をリンクに埋め込み、2端末で同一の指示列を同期再生（開始はリンク作成から2分後）
- 遠隔で指示してもらう：BroadcastChannel で同一ブラウザの別タブ／別ウィンドウ間を接続する簡易版
  - ※ 別端末からの本格的な遠隔操作には WebSocket 等のサーバー連携が別途必要です

## Vercel へのデプロイ

### 方法A：ダッシュボードから（推奨）
1. このフォルダを GitHub リポジトリに push する
2. Vercel で「Add New → Project」→ リポジトリを Import
3. Framework Preset は「Other」、Build Command は空のまま Deploy

### 方法B：CLI
```bash
npm i -g vercel
cd edging-game
vercel --prod
```

## 注意

- 18歳未満は利用できません（年齢確認ゲート付き）。
- 痛みや不調を感じたらすぐ中止してください。医療目的のものではありません。
- アップロードした画像・動画はブラウザ内（Object URL）でのみ再生され、外部送信されません。
